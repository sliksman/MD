## Frame 0 — LE CRIME (0–5 s)
status: built · src: compositions/s0-crime.html
Chantier gris. Deux ouvriers de dos vissent des plaques « BARRE PROTÉINÉE (STANDARD) » sur une ossature.
Gag : le niveau à bulle, chahuté par la chute d'une plaque, revient pile au centre.

## Frame 1 — LE PROCÉDÉ ORDINAIRE (5–13 s)
status: built · src: compositions/s1-procede.html
Caméra qui glisse de machine en machine : MÉLANGER. → PRESSER. → SÉCHER. → « = UN MUR. » (reste).
Gag : le nuage de la presse recouvre l'ouvrier témoin, qui en ressort entièrement gris.

## Frame 2 — LE BASCULEMENT (13–20 s)
status: built · src: compositions/s2-bascule.html
La dalle bordeaux se déroule, le chantier s'enfonce, l'usine tombe d'un coup, MORDU se dresse lettre à lettre,
l'écran tactile affiche « PRÊT ». Gag : le U se lève avec un temps de retard.

## Frame 3 — 01 CACAHUÈTES (20–29 s)
status: built · src: compositions/s3-cacahuetes.html
Convoyeur pas à pas, tampons OK / REFUSÉE. Gag : l'opérateur regarde la caméra, impassible, puis reprend.

## Frame 4 — 02 CARAMEL (29–38 s)
status: built · src: compositions/s4-caramel.html
Étirement jusqu'à « 15 CM MIN. » → voyant ambre ; trop court → voyant bordeaux vif.
Gag : le caramel raté finit dans la poubelle « MENSONGES ».

## Frame 5 — 03 CHOCOLAT (38–45 s)
status: built · src: compositions/s5-chocolat.html
Rideau de chocolat, « MAT. PAS DE VERNIS. », panneau BRILLANT barré.
Gag : la barre trop brillante est éjectée par un petit bras.

## Frame 6 — 04 TEST DU CLOU (45–55 s)
status: built · src: compositions/s6-clou.html
Clou, cale, compteur jusqu'à 13 / 14 ; le clou rebondit sur la MORDU.
Gag : la dernière porte calée reste ouverte, panneau « COURANT D'AIR ».
